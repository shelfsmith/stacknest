Stackroom の後継 · Mac の画像書庫

何千冊の本も、
表紙を眺めて選ぶ。

コミック・画像フォルダ・PDF・電子書籍を、ひとつの書庫に。Apple Silicon と macOS 15 以降にネイティブ対応した、無料でオープンソースのライブラリ管理アプリです。

ダウンロード（v0.17.1） GitHub で見る

macOS 15 以降 · Apple Silicon / Intel（Universal）· MIT ライセンス

書庫・読む・どこでも

01

5,000 冊を超えても軽い書庫

グリッドと一覧、シリーズ・作者・ジャンルでの絞り込み、条件で集めるスマートシェルフ。Finder タグとも同期します。

02

見開きも、縦書きも

zip・rar・7z・PDF・フォルダをそのまま開く内蔵ビューア。電子書籍は縦組み・ルビ・見開きで、書体と色を選べます。

03

iPhone からも、別の Mac からも

共有サーバを ON にすれば、家の LAN や Tailscale 越しにブラウザで読めます。読書位置はどこで読んでも揃います。

右綴じの見開きを、そのまま

ホイールやトラックパッドで 1 回に 1 ページ。ルーペ、ページ送りの演出、キーの割り当ても自由です。

電子書籍は、好みの書体と色で

和文と欧文の書体を別々に。背景と文字の色はプリセットか、自分で選んだ色で。文字の大きさを変えても、読んでいた文に戻ります（電子書籍の表示はベータ版です）。

Web リーダー

アプリを入れなくても、
スマートフォンで読める

Mac の StackNest が書庫を配信し、iPhone や iPad はブラウザで開くだけ。一覧・検索・続きから読む・縦書きの電子書籍まで。共有トークンごとに、読める書庫と権限を分けられます。

Stackroom の書庫をそのまま

Stackroom のライブラリ XML を読み込むだけ。題名・作者・ジャンル・シリーズと巻数・キーワード・評価・既読、プレイリスト（スマートプレイリストも）を、作ってあった表紙ごと引き継ぎます。

AI に書庫を整理させる

コマンドラインの stacknest-cli と MCP サーバで、Claude などから一覧・メタデータの更新・ファイル名の付け直しができます。

$ stacknest-cli list --limit 3 --json

無料でダウンロード

Releases から zip を取り、アプリケーションフォルダへ。自己署名のアプリなので、初回だけシステム設定の「プライバシーとセキュリティ」で開くことを許可してください（手順）。

v0.17.1 を入手
